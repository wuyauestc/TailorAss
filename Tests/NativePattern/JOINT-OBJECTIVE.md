# 联立布料能量

`GarmentCodeJointObjective` 将惯性、源三角膜、主伸长障碍、源内部铰链弯曲与真实接缝纳入同一个可求导的目标：

\[
\Phi(x)=\tfrac12\sum_i m_i h^{-2}\lVert x_i-y_i\rVert^2+
E_{NH}(x)+E_{stretch}(x)+E_{hinge}(x)+
\tfrac1{2c}\sum_e(\lVert A_ex\rVert-(1-r)d_{e,0})^2.
\]

`y` 是当前步固定的预测位置，`h` 为秒，`m` 为原始面积质量（kg），`r` 为本步固定的收缝比例，`c` 为 m/N 的正顺应度。`A` 保留原始附着点的重心权重与独立顶点编号，`d0` 由最终初始摆放的缝合计划给出。此模块不移动位置，不改参考纸样、质量或缝合目标，不添加固定点。

`Prepared` 是底层能量组件，不单独证明整份纸样、人体和缝合来源有效；正式求解仍需通过 `SewnDrape.PreparedInput` 等完整源校验。它从同一套源网格构造膜与弯曲，并检查全部显式裁片分组。零顺应度明确拒绝，不替换成小正数。

`GarmentCodeJointInput.prepare` 已把完整校验封装接入这个生产组件：保留原始人体、全部源绑定、计划和SHA，从原三角面积重新积分SI质量，并与完整源质量核对；不把旧的归一化逆质量直接当作 kg，也不接受人为固定点。实际圆裙＋腰头、带袖上衣＋帽领两份完整源桥接通过，后者保留10片、888行实际缝合。可运行 `sh Tests/NativePattern/run-joint-input.sh`；该检查仍不产生动力学结果。

`Frame.evaluate` 返回总能量、五个分量及真实梯度，`hessianProduct` 返回精确 Hessian 乘向量。缝合受压时的负切向曲率、弯曲的非正定部分均保留；预条件器中的 PSD 近似不能偷偷改变实际目标。目标距离为零时，缝合能量就是光滑的 `|Ax|²/(2c)`，重合两端可以计算梯度与 Hessian；非零目标下两端恰好重合则明确拒绝不可微状态。

`Frame.energyDelta(from:to:)` 使用两组实际存储的 Double 坐标计算稳定能量差，合并 [ELASTIC-ENERGY-DELTA.md](ELASTIC-ENERGY-DELTA.md) 的三个弹性项与惯性／接缝的增量恒等式。它是浮点估计，不承诺任意近静止状态的符号精确；非法域、分支或精度无法判定会返回错误，没有普通总能量相减的静默回退，也不增加接受宽限。整个候选运动路径仍须另作可行性与碰撞检查。

## 验证

```sh
sh Tests/NativePattern/run-joint-objective.sh
```

测试先冻结精确生产源码与真实源 fixture，再按 Swift 5、默认 MainActor、完整并发检查编译运行。综合有限差分同时激活膜、主伸长障碍和弯曲，并覆盖重心接缝、零目标重合、非零目标不可微、负缝合曲率、平移／力矩恒等式、非法输入和取消。

完整真实圆裙＋直腰头源 `28eb56b2…604a35` 保留 2,000 个独立顶点、3,472 个源三角面、69 条实际缝合行与 4,948 个源内部铰链。两种顺应度下联合梯度及 Hessian 乘向量相对差均不超过 `6.31e−9`；另检查全部五项稳定增量的合计。这里的变形状态专门用于导数测试，不是动力学结果。

最终冻结证据：`/private/tmp/TailorAssJointObjectiveElasticIntegrated/delivery-manifest.json`。早期测试把十进制坐标的平面参考态总能量错误要求为逐 bit 零，失败记录保留于独立输出目录；已改为检查重合缝合项与惯性项确实为零，不修改生产能量来满足测试。

**本模块尚未包含人体力、布片自接触、摩擦或时间步求解器，尚未接入 App 成衣路线。导数测试通过不能代表一件衣服已经缝好或收敛。**
