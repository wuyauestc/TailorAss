# 原始裁片的整段形变检查

`GarmentCodeMembranePath` 检查实际存储端点之间的同一条直线路径 `x(t)=(1−t)x0+t*x1`。原始源网格及 `du/dv/A0` 保持不变，源三角形变梯度随 `t` 线性变化。

在每个参数区间的中点，使用 Gram 矩阵的两条奇异值界，再用 Weyl 扰动界 `||ΔF||F × 区间半宽` 包住整个区间的主伸长。单段包络不足时，有限二分同一路径；不插入投影、不换路径、不以采样代替区间证明。

原始二进制64位坐标与形函数系数作为常量；基本加减乘与平方根使用 `nextDown/nextUp` 向外扩展。要求最近舍入环境，不修改调用方浮点状态。默认深度最多12层、全网格最多262,144个区间节点；深度优先存储最多13个待处理区间。解析转动控制在原8层下无法确认、9层后完整通过，因此只增加有限细分深度，未改变形变域或总节点预算。

- `clear`：全部三角形的全部区间严格位于原主伸长开区间内。
- `outsideDomain`：某个端点或中点的包络已证明越界；该参数仅作失败见证，不代替完整区间检查。
- `indeterminate`：数值或有限深度不足以确定。
- `budgetExceeded`：完整工作超过预算，不能接受部分检查结果。

取消明确抛错。此模块不代替每个Newton方向的可行步长、人体／布片连续碰撞或最终源边8%检查。
