# TailorAss（裁缝助手）

面向 iOS 17 及以上系统的原生裁缝工具 App，使用 SwiftUI 构建界面，提供参数化纸样设计、布料排料、裁缝计算、图纸管理和项目记录。

核心制版流程：**选择款式 → 输入人体与服装参数 → 生成 2D 裁片 → 查看尺寸和接缝 → 导出打印 PDF 或纸样 JSON**。纸样计算与 PDF 导出在设备本地运行，无需 Python、NVIDIA Warp 或 Unity。

## 功能介绍

| 功能 | 说明 |
| --- | --- |
| 纸样设计 | 按 GarmentCode 参数与制版逻辑生成二维裁片，支持款式组合、尺寸调整、接缝预览、整张/A4 打印 PDF 及 JSON 导入导出 |
| 布料排料 | 设置面料尺寸，绘制或输入裁片，拖动、旋转、复制和自动排列，查看用布统计并导出排料图片 |
| 裁缝工具 | 布料用量、单位换算、缩水率、缝份、针距换算，以及针线搭配、熨烫温度和尺寸参考 |
| 版型图纸 | 分类浏览、搜索、预览 PDF、上传图纸和收藏 |
| 我的项目 | 记录项目状态、材料、备注和照片，关联排料方案 |
| 我的 | 查看 iCloud 账户状态、收藏和 App 信息 |

纸样设计与布料排料是两个独立入口：前者根据参数生成裁片和接缝，后者管理裁片在面料上的摆放。目前不提供生成纸样自动转入排料的功能。

## 参数化纸样设计

### 款式与组件

| 类别 | 可选款式 |
| --- | --- |
| 上衣 | Shirt、FittedShirt |
| 腰头 | StraightWB、FittedWB |
| 下装 | SkirtCircle、AsymmSkirtCircle、Skirt2、SkirtManyPanels、PencilSkirt、GodetSkirt、SkirtLevels、Pants |

可组合领口、立领、翻领、两片式帽领、袖型、袖口，以及裙层、插片、开衩和装饰切口；支持不对称上衣和合体上衣的无肩带分支。表单按照所选款式及基础裙型显示相应参数分组。

人体参数使用 GarmentCode 的公开字段，长度以 cm 输入，角度以度数输入；派生尺寸由程序自动计算。款式参数保留官方字段、选项和范围。

设计界面使用中文制版名称，提供量体方式、参数用途、单位和允许范围说明；相同字段按款式区分含义，例如腰头高度比例与衣身宽松倍率。款式、组件和裁片名称均以中文显示，原始字段与裁片编号保留在 JSON 数据中。

### 使用方式

1. 在首页打开「纸样设计」，选择上衣、腰头和下装，可按需要组合。
2. 调整对应设计参数及人体尺寸，也可恢复官方默认参数。
3. 点击「生成 2D 纸样」查看裁片。
4. 双指缩放、拖动平移，使用「适配全图」重置视图；点选裁片查看宽高、近似面积及对应接缝。
5. 点击「导出纸样」，选择「导出纸样 PDF」生成整张或 A4 分页文件，也可选择「导出纸样 JSON」保存原始纸样数据；参数页的「导入 GarmentCode 纸样 JSON」可重新打开 JSON 文件。

预览默认显示接缝：每组需要缝合的边使用相同颜色和编号，未缝合的边保持灰色。同片省道也按接缝配对显示。点选彩色边或接缝列表可同时高亮配对边，其他接缝淡化；再次点选或点击「取消高亮」恢复。选择裁片后，列表只显示该片相关的接缝，编号不变。关闭「显示接缝」可查看纯轮廓，接缝组较多时以编号区分重复颜色。导入纸样若有一边关联多组接缝，该边交替显示各组颜色，重复点选可切换高亮。颜色和高亮仅用于预览，不更改裁片几何或导出数据。

全图预览中的短边或密集区域会暂时省略部分编号，避免遮挡；可放大或从列表选中接缝查看。

### 缝份、裁剪线与制作标记

在 2D 预览打开「缝份与标记」（或导出菜单中的「缝份与制版标记」）。先选择裁片，对照制作预览中的边号设置；可用「预览高亮边」定位密集区域。修改后点击「检查并更新制作预览」，确认后点击「完成」应用；取消不会改变已应用设置。原始 2D 总览仍显示制版线，制作编辑器和打印 PDF 显示裁剪线及辅助标记。

- **逐边缝份**：开启「生成缝份与裁剪线」后，普通接缝默认 1 cm、下摆折边默认 3 cm，允许 0～5 cm；每条边可选普通接缝、下摆折边、对折边或不加缝份，也可单独设宽。下摆和对折位置由用户指定，不按形状猜测。省道内边默认不加缝份。
- **裁剪轮廓**：保留原始曲线，以逐边法向外扩和路径布尔合并生成新边界，不是等比放大。凸角使用限长斜接，凹角/狭窄省口合并后提示复核；自交原片、不可信拓扑及异常参数会拒绝生成。对折边仅允许未缝合的直线支撑边，缝份为 0，邻边外扩后仍不能跨过该直线。
- **手动布纹线**：按片启用并设置角度、位置和长度，双箭头必须完整落在真实片身内，越界或空间不足会提示调整。程序不会自动推断正确布纹方向。
- **对折与数量**：对折边添加指向原边的标记；裁剪数量按片设置为 1～20，仅作文字标注，不自动复制或镜像已有裁片。
- **配对定位记号**：可选生成按弧长对应的单/双记号，遵循原接缝方向。仅在两边等长（长度差不超过 0.05 cm）且两侧均可可靠放置时保留；抽褶/吃势等不等长接缝、同片省道及一边多组引用不自动生成。正缝份的短线位于缝份内、深度不超过半缝份；零缝份仅作外向定位线。记号不挖除轮廓，不应直接视作需要剪开的缺口。

实线为裁剪线、虚线为原始制版线；0 缝份边两线重合。**本版尚不做折省省帽及折边折叠后的转角修形，属于需人工复核和试样的辅助制版，不是免检查的工业生产纸样。** 制作提醒会说明省口、尖角及未能生成的记号，请勿剪入原始片身。

设置只在当前纸样预览内保留，返回参数重新生成或重新导入后需重新设置；打印 PDF 会保留制作结果。官方纸样 JSON 仍按原结构和原字节导出，不包含这些附加设置。

### 原尺寸 PDF 与 A4 拼接打印

在 2D 预览的「导出纸样 → 导出纸样 PDF」中选择格式，生成后可缩放预览实际 PDF，再通过「分享或保存 PDF」存入“文件”或发送给打印店。

- **整张 1:1**：全部裁片排列在一张自定义尺寸的大纸上，保留原尺寸，适合绘图仪或打印店输出；界面显示实际纸张宽高。
- **A4 分页拼接**：包含一页缩略总览、打印说明和 10 × 10 cm 校准框，后续为原尺寸拼接页。纸张为 A4 纵向（21 × 29.7 cm），每页纸样区域为 19 × 26.7 cm，左右留边 1 cm、上下留边 1.5 cm，相邻页重叠 1 cm。按行列号排列，沿实线框去除白边，对齐同号 G 十字标记与纸样线后粘贴；虚线是重叠带边界，不是裁片线。总览缩略图不能用于裁剪。
- 可开关接缝颜色与编号；关闭后接缝边使用黑白线，已设置的制作标记仍保留。裁片名称、数量、校准框和打印比例不变，预览中的缩放、平移、高亮和裁片筛选不会影响导出。
- 辅助文字避让裁剪线与其他标注；密集区域无法放下时会提示并省略文字（配对定位文字成对省略），定位短线仍保留，须按接缝编号核对。

**打印必须选择「实际大小」或 100%，关闭「适应页面」及自动缩放。先量校准框，确认长和宽均为 10 cm 后再打印整套。** PDF 使用原生矢量轮廓，长度换算固定为 1 cm = 72 / 2.54 PDF 点。

默认仍为 **不含缝份**，须先在制作设置中启用缝份才能导出外扩裁剪线；不提供自动布纹推断或自动挖除的刀口。打印排版不旋转或缩放裁片，不是布料优化排料。为避免异常文件消耗过多资源，排版单边最多 500 cm，A4 拼接预算最多 200 张（另加说明页）；两种格式共用这组排版安全检查。

### 数据与计算

导出采用 GarmentCode/PyGarment 兼容的 JSON 结构，包含裁片顶点、直线与曲线边、接缝配对、参数及生成器信息。支持直线、圆弧、二次和三次 Bezier 曲线。导入文件通过几何与引用校验后进入预览，再次导出时保留原始文件字节。

实现参照固定 GarmentCode 版本 `d449629979028123a5c4dc9e732a2ec19b7fce31`，保留其参数、人体派生公式和款式组合逻辑。曲线拟合使用原生稳定求解器，结果允许小幅数值差异；验收轮廓偏差上限为袖片/袖口 3 mm、帽领 6 mm，接缝长度差相对官方的变化小于 0.5 mm。

当前功能聚焦二维纸样、制作标记、打印 PDF 和 JSON 数据，不包含 3D 仿真、成衣预览或完整工业化折省/折边修形。软件对照验证不能代替个人尺寸的实物合体检查，首次制作建议先做试样。

## 布料排料

在首页打开「布料排料」，新建或编辑排料方案。裁片可通过尺寸输入，或使用手绘、矩形、椭圆、扇形工具创建。

画板支持拖动、旋转、复制、删除、缩放和平移，使用碰撞检测限制越界或重叠摆放；「一键重排」尝试多个角度自动排列。页面显示已排片数、已用布长和余料率，可将排料图保存到相册，也可保存方案并关联项目。

## 运行项目

### 开发环境

- macOS 与 Xcode，安装所需的 iOS SDK 和 Simulator。
- App 部署目标为 iOS 17.0。
- 工程文件名为 `TrailorAss.xcodeproj`，Scheme 为 `TrailorAss`。

在 Xcode 打开工程，选择 iPhone 模拟器或已连接的真机，点击运行。也可在仓库根目录构建模拟器版本：

```sh
xcodebuild \
  -project TrailorAss.xcodeproj \
  -scheme TrailorAss \
  -configuration Debug \
  -destination 'generic/platform=iOS Simulator' \
  -derivedDataPath /private/tmp/TailorAssBuild \
  CODE_SIGNING_ALLOWED=NO \
  build
```

构建后可通过 Xcode 或 Device Hub 启动和调试 App。模拟器中的图纸、项目和排料存储使用本地 Mock 实现，便于界面联调；纸样设计运行真实的 Swift 计算链。

### 真机与 CloudKit

真机的图纸、项目和排料数据使用 CloudKit。运行前在 Xcode 的 Signing & Capabilities 中配置开发团队，并确认 iCloud 容器权限。

- Bundle ID：`com.trailorass.app`
- CloudKit 容器：`iCloud.com.trailorass.app`
- 公共库：`Pattern`
- 私有库：`Favorite`、`Project`、`Layout`

云端写入及私有库操作需要登录 iCloud；本地纸样计算不依赖 iCloud。开发环境与生产环境的 CloudKit Schema 分开管理，发布前需确认生产环境的记录类型、索引和权限。

存储接口位于 `TrailorAss/Services/`，模拟器和真机实现由 `StoreFactory`、`ProjectStoreFactory`、`LayoutStoreFactory` 选择。

## 验证与测试

在仓库根目录运行纸样联合验收：

```sh
sh Tests/NativePattern/run-acceptance.sh
```

验收覆盖 356 个固定官方纸样对照，包括款式组合、两组人体尺寸、领袖组件、裙装细节，以及拓扑、接缝、曲线轮廓、求解质量、扰动稳定性、JSON 数据往返、中文显示和接缝显示索引。接缝索引与点选命中测试可单独运行 `sh Tests/NativePattern/run-seams.sh`。

PDF 专项测试：`sh Tests/NativePattern/run-pdf-plan.sh` 检查原尺寸排版、曲线边界与重叠分页；`sh Tests/NativePattern/run-pdf.sh` 重新打开实际 PDF，检查页数、物理页尺寸、10 cm 校准方框、矢量路径、拼接页标记与数据不变性。它们不代替真实打印机的比例校准。

制作专项测试：`sh Tests/NativePattern/run-allowance.sh` 检查逐边异宽、曲线、尖凹角、对折边和异常轮廓；`sh Tests/NativePattern/run-marks.sh` 检查手动布纹、对折及按弧长配对的定位线；`sh Tests/NativePattern/run-manufacturing-pdf.sh` 检查设置验证、原始数据不变性，以及制作信息在整张/A4 PDF 中的物理尺寸和矢量输出。上述脚本已纳入联合验收。PDF 样例可用 `GARMENTCODE_PDF_OUTPUT_DIR=output/pdf` 保留作视觉复核。

- [测试说明](Tests/NativePattern/README.md)：完整命令、验收范围与诊断方式。
- [验收记录与数值界限](Tests/NativePattern/Reports/2026-10-23/acceptance.md)：对照证据、轮廓叠加图及使用限制。

## 代码结构

| 目录 | 内容 |
| --- | --- |
| `TrailorAss/App/` | App 入口、主题和导航 |
| `TrailorAss/Models/` | 纸样参数、几何、款式程序、组合生成器，以及图纸/项目/排料模型 |
| `TrailorAss/Views/` | 首页、纸样设计、排料、图纸、项目和工具界面 |
| `TrailorAss/ViewModels/` | 界面状态与业务协调 |
| `TrailorAss/Services/` | CloudKit、本地存储实现和排料碰撞检测 |
| `TrailorAss/Resources/` | 官方参数目录、样例纸样和装饰曲线资源 |
| `Tests/NativePattern/` | 官方对照样例、原生验收脚本和报告 |
