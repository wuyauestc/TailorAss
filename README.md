# TailorAss（裁缝助手）

面向 iOS 17 及以上系统的原生裁缝工具 App，使用 SwiftUI 构建界面，提供参数化纸样设计、布料排料、裁缝计算、图纸管理和项目记录。

核心制版流程：**选择款式 → 输入人体与服装参数 → 生成 2D 裁片 → 查看尺寸和接缝 → 导出打印 PDF 或纸样 JSON**。纸样计算与 PDF 导出在设备本地运行，无需 Python、NVIDIA Warp 或 Unity。

## 功能介绍

| 功能 | 说明 |
| --- | --- |
| 纸样设计 | 按 GarmentCode 参数与制版逻辑生成二维裁片，支持款式组合、尺寸调整、接缝预览、整张/A4 打印 PDF 及 JSON 导入导出 |
| 裙装与腰头 3D 试验 | 从当前圆裙、双片裙或独立腰头裁片生成网格，在本地计算标准人台上的形态，检查布片自交及人体面交叉；支持实验面料、旋转、缩放、接缝显示与 OBJ 导出 |
| 布料排料 | 设置面料尺寸，绘制或输入裁片，拖动、旋转、复制和自动排列，查看用布统计并导出排料图片 |
| 裁缝工具 | 布料用量、单位换算、缩水率、缝份、针距换算，以及针线搭配、熨烫温度和尺寸参考 |
| 版型图纸 | 分类浏览、搜索、预览 PDF、上传图纸和收藏 |
| 我的项目 | 记录项目状态、材料、备注和照片，关联排料方案 |
| 我的 | 查看 iCloud 账户状态、收藏和 App 信息 |

纸样设计与布料排料是两个独立入口：前者根据参数生成裁片和接缝，后者管理裁片在面料上的摆放。目前不提供生成纸样自动转入排料的功能。

## 参数化纸样设计

### 基础与高级模式

进入「纸样设计」后，右上角可选择「基础 / 高级」，默认打开基础模式。两种模式共用同一份设计与人体数据；切换只改变界面，不恢复默认，不重置领口、袖口或其他高级参数，也不更换制版内核。

- **基础模式**：选择款式组件、编辑人体尺寸、直接输入厘米长度。当前支持普通对称上衣的后中衣长、双片裙与圆裙的裙身长度、平下摆无装饰切口铅笔裙的前片垂直裙身长、无独立裤口组件裤装的前片垂直裤身长，以及腰头高度。每项均说明具体量法与有效范围；裙裤身长度不包含腰头，所有长度不含缝份和折边余量。普通上衣另提供宽松程度和有袖／无袖选项，袖长及复杂细节仍在高级模式调整。
- **高级模式**：保留完整 GarmentCode 参数、款式组合与全部人体字段。基础模式无法可靠表达的合体上衣、复杂裙型、不对称或独立领／裤口组件会显示说明，继续沿用原参数，不显示无效的长度输入。
- **高级自定义保留**：基础模式会提示当前活跃、未在基础界面表示的高级自定义项。修改一个厘米字段只换算其对应原始参数；未触碰的参数不变。已显式填写的厘米长度在基础模式修改人体尺寸后会尝试保持，超出新范围时要求修正，不自动截断；无效长度会阻止生成和模式切换，可明确放弃输入恢复当前参数显示。
- **完整量体数据**：基础模式通过「编辑全部人体尺寸」打开全部 26 项，和高级模式共用数据，不按身高猜测缺失尺寸。初始数据来自示例人体，界面会提醒逐项核对；人体与设计编辑状态目前仅保留在当前页面，并非已保存的个人量体档案。

厘米输入是对现有参数的换算，不是对生成后的裁片做等比缩放。组合款分别编辑组件长度，不将它们冒充整件成衣总长；曲线长度、径向裙长与垂直高度须按字段说明区分。

### 图文帮助网站（私有预览）

在「纸样设计」右上角点击问号「帮助」，会在浏览器打开 [裁缝助手 · GarmentCode 纸样设计指南](https://tailorass-pattern-guide-20261024.wellbud33.chatgpt.site)。页面开头另有当前模式的说明入口：基础模式打开厘米输入指南，高级模式打开完整参数词典。切换到网页不会将当前人体或设计数据传给网站。

帮助站点目前保持**所有者私有**，需要用拥有该网站权限的账号登录，并未公开给所有 App 用户。网页需要网络，不是离线内置文档。

- 覆盖 12 款主版型，每款有原创结构示意、上游固定配置真实参考裁片、人体依赖、参数联系、调整次序与 3 个实例；可切换结构／真实裁片／并排对照。
- 提供全部 122 项设计参数、26 项人体输入和 7 项派生公式，支持中文与原始路径检索；另有领口、领部、衣袖、接缝、制作检查和 A4 打印章节。
- 5 组单参数切换示例共 15 份图，使用当前 Swift 生成器真实计算；同组共享尺度与画布，明确标示参考取值与公开默认值。
- **交互参数实验室**：帮助网站新增「左侧参数、右侧裁片」界面，首批支持宽松上衣、双片裙、圆裙、铅笔裙和裤装，每款两项参数可同时拖动；即时查看真实裁片、尺寸差量及默认轮廓叠加。全部离散参数组合由本 App Swift 内核预先实算，网页直接显示对应精确矢量结果，不插值或等比拉伸。人体及未开放的参数固定为公开示例，不是完整在线制版；无需重装 App 即可通过原有帮助入口访问更新。
- 结构图中的“标准示意”仅指典型结构参考，不是国家或行业标准，也不是可直接裁剪的 1:1 图。网页参考尺寸不是你的个人尺寸；正式制作仍需在 App 内生成、校准打印并试样。

网站源码独立保存在同级 `../GarmentCodeHelp/`，部署输出为 `dist/`；`scripts/export-help.sh` 从本 App 的真实目录、本地化、导入器与计算链重建参考资料，`node scripts/check-site.mjs` 校验覆盖和资产。网站使用独立私有托管源仓库，不影响 App 的 Git 分支。固定 GarmentCode 版本与本 App 一致，来源链接及上游 MIT 许可见网站「版本与来源」。

参数说明同时澄清：`pants.width` 是总裆部延伸量倍率，而非整条裤子的统一宽松倍率；`levels-skirt.length` 是用于基裙与接层分配的腿长段比例，基裙另有腰臀高度贡献。这里只修正中文解释，不更改计算、原始键名、范围和默认值。

### 款式与组件

| 类别 | 可选款式 |
| --- | --- |
| 上衣 | Shirt、FittedShirt |
| 腰头 | StraightWB、FittedWB |
| 下装 | SkirtCircle、AsymmSkirtCircle、Skirt2、SkirtManyPanels、PencilSkirt、GodetSkirt、SkirtLevels、Pants |

可组合领口、立领、翻领、两片式帽领、袖型、袖口，以及裙层、插片、开衩和装饰切口；支持不对称上衣和合体上衣的无肩带分支。表单按照所选款式及基础裙型显示相应参数分组。

人体参数使用 GarmentCode 的公开字段，长度以 cm 输入，角度以度数输入；派生尺寸由程序自动计算。款式参数保留官方字段、选项和范围。

分层裙会沿用上一层的真实下摆接口来计算下一层，已修正不对称圆裙接层在内部标签移除后误读上口的问题。24 组固定上游完整裁片对照通过；详细计算与三维准备边界见 [分层裙接口验证](Tests/NativePattern/LEVELS-HEM.md)。

设计界面使用中文制版名称，提供量体方式、参数用途、单位和允许范围说明；相同字段按款式区分含义，例如腰头高度比例与衣身宽松倍率。款式、组件和裁片名称均以中文显示，原始字段与裁片编号保留在 JSON 数据中。

### 使用方式

1. 在首页打开「纸样设计」，选择上衣、腰头和下装，可按需要组合。
2. 在基础模式用厘米调整支持的长度；需要修改完整设计参数时，在右上角切到高级模式。核对人体尺寸，也可明确选择恢复官方默认参数。
3. 点击「生成 2D 纸样」查看裁片。
4. 双指缩放、拖动平移，使用「适配全图」重置视图；点选裁片查看宽高、近似面积及对应接缝。
5. 点击「导出纸样」，选择「导出纸样 PDF」生成整张或 A4 分页文件，也可选择「导出纸样 JSON」保存原始纸样数据；参数页的「导入 GarmentCode 纸样 JSON」可重新打开 JSON 文件。

预览默认显示接缝：每组需要缝合的边使用相同颜色和编号，未缝合的边保持灰色。同片省道也按接缝配对显示。点选彩色边或接缝列表可同时高亮配对边，其他接缝淡化；再次点选或点击「取消高亮」恢复。选择裁片后，列表只显示该片相关的接缝，编号不变。关闭「显示接缝」可查看纯轮廓，接缝组较多时以编号区分重复颜色。导入纸样若有一边关联多组接缝，该边交替显示各组颜色，重复点选可切换高亮。颜色和高亮仅用于预览，不更改裁片几何或导出数据。

全图预览中的短边或密集区域会暂时省略部分编号，避免遮挡；可放大或从列表选中接缝查看。

### 缝份、裁剪线与制作标记

在 2D 预览打开「缝份与标记」（或导出菜单中的「缝份与制版标记」）。先选择裁片，对照制作预览中的边号设置；可用「预览高亮边」定位密集区域。修改后点击「检查并更新制作预览」，确认后点击「完成」应用；取消不会改变已应用设置。原始 2D 总览仍显示制版线，制作编辑器和打印 PDF 显示裁剪线及辅助标记。

- **逐边缝份**：开启「生成缝份与裁剪线」后，普通接缝默认 1 cm、下摆折边默认 3 cm，允许 0～5 cm；每条边可选普通接缝、下摆折边、对折边或不加缝份，也可单独设宽。下摆和对折位置由用户指定，不按形状猜测。省道内边默认不加缝份。
- **裁剪轮廓**：保留原始曲线，以逐边法向外扩和路径布尔合并生成新边界，不是等比放大。凸角使用限长斜接，凹角/狭窄省口合并后提示复核；自交原片、不可信拓扑及异常参数会拒绝生成。对折边仅允许未缝合的直线支撑边，缝份为 0，邻边外扩后仍不能跨过该直线。
- **手动布纹线**：按片启用并设置角度、位置和长度，双箭头必须完整落在真实片身内，越界或空间不足会提示调整。程序不会自动推断正确布纹方向。
- **对折与数量**：对折边添加指向原边的标记；裁剪数量按片设置为 1～20，仅作文字标注，不自动复制或镜像已有裁片。
- **配对定位记号**：可选生成按弧长对应的单/双记号，遵循原接缝方向。仅在两边等长（长度差不超过 0.05 cm）且两侧均可可靠放置时保留；抽褶/吃势等不等长接缝、同片省道及一边多组引用不自动生成。正缝份的短线位于缝份内、深度不超过半缝份；零缝份仅作外向定位线。记号不挖除轮廓，不应直接视作需要剪开的缺口。

实线为裁剪线、虚线为原始制版线；0 缝份边两线重合。**本版尚不做折省省帽及折边折叠后的转角修形，属于需人工复核和试样的辅助制版，不是免检查的工业生产纸样。** 制作提醒会说明省口、尖角及未能生成的记号，请勿剪入原始片身。

设置只在当前纸样预览内保留，返回参数重新生成或重新导入后需重新设置；打印 PDF 会保留制作结果。官方纸样 JSON 仍按原结构和原字节导出，不包含这些附加设置。

### 原尺寸 PDF 与 A4 拼接打印

在 2D 预览的「导出纸样 → 导出纸样 PDF」中选择格式，生成后可缩放预览实际 PDF，再通过「分享或保存 PDF」存入“文件”或发送给打印店。

- **整张 1:1**：全部裁片排列在一张自定义尺寸的大纸上，保留原尺寸，适合绘图仪或打印店输出；界面显示实际纸张宽高。
- **A4 分页拼接**：包含一页缩略总览、打印说明和 10 × 10 cm 校准框，后续为原尺寸拼接页。纸张为 A4 纵向（21 × 29.7 cm），每页纸样区域为 19 × 26.7 cm，左右留边 1 cm、上下留边 1.5 cm，相邻页重叠 1 cm。按行列号排列，沿实线框去除白边，对齐同号 G 十字标记与纸样线后粘贴；虚线是重叠带边界，不是裁片线。总览缩略图不能用于裁剪。
- 可开关接缝颜色与编号；关闭后接缝边使用黑白线，已设置的制作标记仍保留。裁片名称、数量、校准框和打印比例不变，预览中的缩放、平移、高亮和裁片筛选不会影响导出。
- 辅助文字避让裁剪线与其他标注；密集区域无法放下时会提示并省略文字（配对定位文字成对省略），定位短线仍保留，须按接缝编号核对。

**打印必须选择「实际大小」或 100%，关闭「适应页面」及自动缩放。先量校准框，确认长和宽均为 10 cm 后再打印整套。** PDF 使用原生矢量轮廓，长度换算固定为 1 cm = 72 / 2.54 PDF 点。

默认仍为 **不含缝份**，须先在制作设置中启用缝份才能导出外扩裁剪线；不提供自动布纹推断或自动挖除的刀口。打印排版不旋转或缩放裁片，不是布料优化排料。为避免异常文件消耗过多资源，排版单边最多 500 cm，A4 拼接预算最多 200 张（另加说明页）；两种格式共用这组排版安全检查。

### 数据与计算

导出采用 GarmentCode/PyGarment 兼容的 JSON 结构，包含裁片顶点、直线与曲线边、接缝配对、参数及生成器信息。支持直线、圆弧、二次和三次 Bezier 曲线。导入文件通过几何与引用校验后进入预览，再次导出时保留原始文件字节。

**轮廓交叉提示**：生成时会提前检查可确认的直线／圆弧内部交叉，显示裁片名称、边号及参数调整建议，避免将已知自交轮廓继续用于制作。导入的自交纸样仍可预览和原样导出 JSON，但打印、缝份及 3D 入口会禁用；修正参数后可以重新生成，不会禁用整个款式。这个提前检查不覆盖所有曲线组合，未出现提示不等于纸样已通过全部制作或三维检查。详见 [轮廓诊断与验证](Tests/NativePattern/SOURCE-CONTOUR-DIAGNOSTICS.md)。

实现参照固定 GarmentCode 版本 `d449629979028123a5c4dc9e732a2ec19b7fce31`，保留其参数、人体派生公式和款式组合逻辑。曲线拟合使用原生稳定求解器，结果允许小幅数值差异；验收轮廓偏差上限为袖片/袖口 3 mm、帽领 6 mm，接缝长度差相对官方的变化小于 0.5 mm。

正式制版功能聚焦二维纸样、制作标记、打印 PDF 和 JSON 数据；另提供下述裙装与独立腰头 3D 实验，不代表全部款式已有成衣仿真，也不包含完整工业化折省/折边修形。软件对照验证不能代替个人尺寸的实物合体检查，首次制作建议先做试样。

**组合参数规则**：独立「裤装 + 腰头」统一按裤装的腰位参数生成；更改普通裙装腰位不会改变这套裤装纸样。「插片裙」使用铅笔裙作为基础时，按上游规则关闭基础裙的四类开衩，保留原设计参数记录；单独铅笔裙的开衩仍正常生效。这些边界另有 25 组固定官方完整几何对照，不代表已完成三维合体。 合体上衣搭配圆裙、不对称圆裙或多片裙时，按上游规则使用自然腰位；宽松上衣仍读取选择的裙腰位。该分支另通过48组完整纸样与摆放对照，保存的原始设计参数不变。

### 裙装离线 3D 试验

1. 在参数页只选择下装「圆裙」或「双片裙」，上衣和腰头均为「不添加」，关闭裙身切口。示例人体可直接生成默认双片裙；圆裙对照使用默认径向裙长 40.54146 cm 和展开量 0.5、0.75、1.0。
2. 生成 2D 纸样后，点击预览右上角的立方体图标，选择「裙装与腰头预览」。选择标准人体或参考圆台、柔软／中等／挺括实验面料，再点击「生成离线 3D」。运算在后台执行，可取消；取消后旧任务不会回填结果。修改配置会清除旧结果，须重新计算。
3. 拖动旋转、双指缩放，可显示／隐藏人台和橙色侧缝，查看收敛提示及原纸样尺寸，并导出以米为单位、Y 轴向上的 OBJ。原纸样 JSON 和打印 PDF 不受影响。

计算采用独立的 Swift 距离约束实验核心，RealityKit 负责展示，保持 App 的 iOS 17 部署目标。圆裙从真实二维圆弧和径向边建立网格；双片裙从实际矩形或梯形裁片建立网格，保留前后片不同宽度、真实侧缝配对及平面参考长度。先记录各片原始参考度量，再合并接缝的运动顶点。Swift 计算核心可在 Mac 上重复测试，也可在 iPhone 本地运行，不依赖联网、NVIDIA GPU、Unity 或 Python 服务。

**双片裙的抽褶与尺寸**：默认抽褶倍率 1.3，示例人体腰围 84.3 cm 对应原纸样腰口总长 109.6 cm。腰口采用按原始边长构造的外向褶皱辅助支撑环，保留这段褶量，不把裁片缩成身体腰围；这不是已缝制真实腰头的仿真。结果分别显示原纸样腰口总长、支撑腰围和抽褶倍率。双片裙的裙长是垂直长度，`flare` 是每片下摆每侧增加的厘米数，不能与圆裙径向长度或展开倍率混用。双片裙仅约束实际三角网格的边，保留沿三角边折叠的自由度；初始装配使用人体逐层截面的躯干／双腿凸包，排除手臂和手掌。增加裙摆时，侧缝腰角对齐外向褶峰，给梯形裁片保留展开空间。如果原裁片围度无法包住该截面，会明确提示增加抽褶或裙摆增量。

**标准人体与碰撞**：默认使用固定来源的 MakeHuman CC0 人体网格，按腰围、臀围及高度做有限拟合；它不是个人身体重建。1 cm 有符号距离场与显示网格同源，已覆盖脚底、躯干、头部和双手，体积约 6.02 MB。扩展上半身覆盖时，全部旧下半身采样字节保持原值，人体网格也未改变。本节说明圆裙和双片裙，独立腰头见下一节；上装装配尚未接入。自然腰位使用有间距的辅助支撑；圆裙沿外移后的闭合轮廓重新按弧长布点，双片裙保留原抽褶边长。原圆台和原求解配置保留为回归对照。

**表面自碰撞**：使用空间索引检查顶点与三角面、边与边，并修正面内穿插；末态另做非相邻三角面交叉检查。收敛要求保留持续稳定、最大网格边应变小于 8%、布片顶点对人体的穿入估计小于 3 mm，并要求末态布片三角面交叉数为 0。这是离散检查，不能保证跨时间步无穿透；人体面接触另作独立检查。

**人体面接触**：标准人体模式额外使用同一可见闭合人体的三角网格和空间索引，按交叉位置的重心权重修正顶点／面与边接触，末态要求布片与人体的真实三角面交叉数为 0。它解决了布片顶点在体外、面片中部却穿入人体的问题。八组对照均通过原有边应变门槛和两类交叉检查；独立复核还确认全部 6,432 个布片顶点及 11,904 个三角面中心在人体外。网格接触目标为 0.5 mm，距离场顶点目标为 2.5 mm，辅助腰口支撑目标为 5 mm；这些是数值间距，不是标定面料厚度或全局最小间隙证书。检查使用离散末态，不保证连续运动无穿插，也不能代替实物合体检查。

**面料实验预设**：三档名为柔软／中等／挺括，提供 120／180／280 g/m² 的数值面料与不同距离柔顺度，不冒充真丝、棉布或牛仔布的实测物性。质量按原二维三角面积分配，合并接缝时汇总质量，固定点质量仍计入布料总量；对角剪切与普通拉伸约束分别处理。三档已验证实际生成几何有变化，尚无实物样布的拉伸、弯曲和摩擦标定。

**范围和限制**：支持无腰头、无切口的两片圆裙（圆周倍数 0.1～1）及普通双片裙。双片裙仅支持自然腰位、1～1.5 倍统一抽褶、0～20 cm 裙摆增量、5～150 cm 垂直裙长和完整普通侧缝。标准人体目前仅支持自然腰位。其他款式或不支持的组件会明确拒绝；范围内尺寸也可能因臀部空间不足等原因无法收敛。弯曲仍采用二阶距离近似，接缝间隙为共享顶点的构造性质。收敛提示不等于真实合身或与 GarmentCode 的物理结果等价；未收敛或检测到交叉的结果会明确标注。现有圆裙 7 项集成对照包含旧版基线、三种展开量、加长圆裙与两种额外面料，不能代表全部尺寸组合已验证。

Apple 的 iOS 27 原生布料 API 已做编译可用性检查，但公开接口尚未验证任意裁片的接缝约束和二维参考度量，因此没有直接用于本版的多裁片求解。测试设备计划为 iPhone 17 Pro／iOS 27.0.1；模拟器能验证界面和计算链，耗时、内存及发热仍须在真机测量。

### 独立腰头 3D

在「纸样设计」选择腰头「直条腰头」或「贴体弧形腰头」，上衣和下装均选「不添加」，生成二维纸样后点击右上角立方体，选择「裙装与腰头预览」。腰头页面使用标准人体，并以腰部近景显示；可以切换实验面料、旋转、复位和导出 OBJ。

## 运行项目

### 开发环境

- macOS 与 Xcode 27，安装所需的 iOS SDK 和 Simulator（3D 计算快照使用编译器的 `nonisolated` 类型支持）。
- App 部署目标为 iOS 17.0。
- 工程文件名为 `TrailorAss.xcodeproj`，Scheme 为 `TrailorAss`。

在 Xcode 打开工程，选择 iPhone 模拟器或已连接的真机，点击运行。也可在仓库根目录构建模拟器版本：

```sh
xcodebuild \
  -project TrailorAss.xcodeproj \
  -scheme TrailorAss \
  -configuration Debug \
  -destination 'generic/platform=iOS Simulator' \
  -derivedDataPath /private/tmp/TailorAssBuild \
  CODE_SIGNING_ALLOWED=NO \
  build
```

构建后可通过 Xcode 或 Device Hub 启动和调试 App。模拟器中的图纸、项目和排料存储使用本地 Mock 实现，便于界面联调；纸样设计运行真实的 Swift 计算链。

### 真机与 CloudKit

真机的图纸、项目和排料数据使用 CloudKit。运行前在 Xcode 的 Signing & Capabilities 中配置开发团队，并确认 iCloud 容器权限。

- Bundle ID：`com.trailorass.app`
- CloudKit 容器：`iCloud.com.trailorass.app`
- 公共库：`Pattern`
- 私有库：`Favorite`、`Project`、`Layout`

云端写入及私有库操作需要登录 iCloud；本地纸样计算不依赖 iCloud。开发环境与生产环境的 CloudKit Schema 分开管理，发布前需确认生产环境的记录类型、索引和权限。

存储接口位于 `TrailorAss/Services/`，模拟器和真机实现由 `StoreFactory`、`ProjectStoreFactory`、`LayoutStoreFactory` 选择。

专项检查真实圆裙／双片裙尺寸、原基线不变、同源人体碰撞场、穿插修复、面积质量守恒、面料敏感性、取消及不支持组合。标准人体使用 32 次约束迭代，旧版基线保持 24 次；没有放宽原通过标准。圆裙七组结果的顶点与三角形保持原值；双片裙五组通过持续稳定、边应变小于 8%、布片顶点对人体的穿入估计小于 3 mm 和末态自交数为 0 的检查。默认输入与锁定官方 JSON 比较，并检查侧缝拓扑、三角网格边约束和原始平面度量。Mac 与模拟器耗时不能代替真机性能，性能测试应使用优化构建，Debug 运算可能明显较慢。

PDF 专项测试：`sh Tests/NativePattern/run-pdf-plan.sh` 检查原尺寸排版、曲线边界与重叠分页；`sh Tests/NativePattern/run-pdf.sh` 重新打开实际 PDF，检查页数、物理页尺寸、10 cm 校准方框、矢量路径、拼接页标记与数据不变性。它们不代替真实打印机的比例校准。

制作专项测试：`sh Tests/NativePattern/run-allowance.sh` 检查逐边异宽、曲线、尖凹角、对折边和异常轮廓；`sh Tests/NativePattern/run-marks.sh` 检查手动布纹、对折及按弧长配对的定位线；`sh Tests/NativePattern/run-manufacturing-pdf.sh` 检查设置验证、原始数据不变性，以及制作信息在整张/A4 PDF 中的物理尺寸和矢量输出。上述脚本已纳入联合验收。PDF 样例可用 `GARMENTCODE_PDF_OUTPUT_DIR=output/pdf` 保留作视觉复核。
