# 可见人体表面的真实截面

`GarmentCodeBodySections.slice` 接受精确可见人体的 `positions`、`triangleIndices` 和显式平面，返回全部独立闭合交线环及其周长、面积、边界与原始三角面来源。它不取凸包、不桥接双腿/双臂、不选最大环、不合并环的周长，也不拟合人体。

已有 `GarmentCodeSkirtDrape.sectionHull` 是控制裙型用的私有凸包，不是保留全部组件的截面 API；因此本实现另设独立纯几何入口，没有替换旧控制或改变其算术。没有改 StandardBody 的默认人体、已有有限尺寸变形、SDF、NativeAssembly 初始化选择或产品页面。

## 方法与明确限制

- 验证有限坐标、索引、非退化且不重复的三角面、每条源边恰好两个反向面、每个顶点单一闭合邻接扇、无闲置顶点、每个连通组件非零体积。不会修补开放面、焊点或翻面。
- 对每个原始三角面直接与平面求交。交点身份使用原始边的两个顶点 ID，共边交点只算一次；没有按距离量化或合并坐标。
- 交线构成二度图，逐个追踪全部闭合环；每条边界保留原三角面 ID，每个交点保留原边 ID 和插值参数。环沿输出平面的正法向统一定向，首尾闭合边显式保留，不重复最后顶点。
- 周长由真实交线折线积分，面积为平面投影多边形面积。结果是三角面网格的数值截面，不是光滑人体的精确解析曲线。圆柱测试区分多边形截面真值与光滑圆误差。
- 平面穿过或数值上接近源顶点、包含共面三角面，返回 `indeterminate/sourceFeature` 和完整源 ID；触碰/交叉轮廓等歧义也返回 indeterminate。没有暗中平移平面，indeterminate 不携带部分“可用”测量。
- 默认声明平面数值带为 `1e-11 m`，另加保守的二进制浮点舍入带。全部预算有界，计算可取消；取消抛错，不返回部分截面。未提供区间证明或整个人体全局自交证书。
- `bodyGeometrySHA256` 使用与刚体人体 proof 相同的 `rigid-clearance-visible-body-v1` 小端字节约定，绑定每个 Double 位模式、完整顶点与原始面索引顺序。输出同时保存原始平面、误差带、来源数量和最大平面残差。

多个环的周长或面积不能自动视为人体围度。躯干、手臂、腿的选择需要后续明确的解剖位置/区域规则；环序只是源边 ID 的稳定顺序，没有人体语义。嵌套环也没有被自动解释为“扣除孔洞”的联合面积。

## 测试与实际人体

运行 `sh Tests/NativePattern/run-body-sections.sh`。默认创建唯一结果目录，导出同一个 `GARMENTCODE_BODY_SECTIONS_OUTPUT` 给程序与独立检查器；`GARMENTCODE_BODY_SECTIONS_KEEP_SNAPSHOT=1` 保留完整输入快照。Swift 5、默认 MainActor、完整并发检查、warnings-as-errors。

解析测试包括正交立方体（周长 8 m、面积 4 m²）、斜切立方体的独立矩形公式、32/128/512 边圆柱的规则多边形公式及向圆的收敛、两个分离实体的两个独立环、空截面。另验证平面穿顶点/共面不隐藏偏移、相交轮廓拒绝、12 项非法输入/预算/取消、顶点夹点非流形拒绝、几何 SHA 改变和同源并发确定性。

默认人体与女性参数人体各计算 5 个平面，10 个平面全部 complete。所有周长、面积、环数、源边插值、原三角面边界和几何 SHA 均由独立 Python 标量求交/图追踪与 `math.fsum` 再核验。
